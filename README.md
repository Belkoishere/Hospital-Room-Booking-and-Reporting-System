# CSD204A2 Code

HRBRS (Hospital Room Booking and Reporting System) is a console application written
in TypeScript for a programming assignment.

Main functionailty of the HRBRS:

Room management:
- Adding rooms
- Adding room types

Room booking:
Room suitability determines whether a room is suitable
or not for a patient, a patient may not be booked into a room 
that is unsuitable.

Patient management:
- Registering patients

Reporting
- Available rooms report
- Patient numbers report
- Average stay report
- Room occupancy report

Structure of HRBRS
The structure of this application is based on a UML class diagram (in design folder) 
that I created which implements appropraite design patterns to ensure the readability,
maintainability and extensibility of the codebase.
